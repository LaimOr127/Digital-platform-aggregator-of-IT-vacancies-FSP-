## Коротко об устройстве

```
Браузер ──HTTPS──> Caddy ──/api/*──> api (FastAPI) ──> PostgreSQL (RLS)
                        └──/*──────> web (статика React)
worker (фоновые задачи) ──> PostgreSQL, ФСП (мок или реальный API), SMTP
migrate (one-shot): alembic upgrade head + выдача прав роли приложения
```

- **backend/** — FastAPI: `api` (HTTP) → `services` (сценарии и права) → `repositories` (запросы) → `models`.
- **frontend/** — Vite + React + TypeScript, три портала: `/app` (кандидат), `/company` (работодатель),
  `/admin` (модерация).
- **fsp-mock/** — мок API ФСП с теми же контрактами, что ждёт бэкенд.
- **deploy/** — compose-файл на каждый сервис, Caddy; любая комбинация поднимается `make up S="..."`.
- **scripts/** — генерация `.env`, смоук-тест, проверка прав БД, нагрузочный тест k6.
